Where to find PRDR files

Documents\Rockstar Games\Red Dead Redemption 2\Profiles\<your-id>\

Photo files start with “PRDR” and have no file extension. On Android, pick “All files” in the file chooser if they look greyed out.

Deploy with GitHub Actions

  1. Create a repository and upload every file from the project, keeping the folder layout.
  2. Make sure .github/workflows/deploy.yml is included.
  3. Open Settings → Pages and set Source to GitHub Actions.
  4. Push to main. Your site goes live in about a minute.

Tips
