# PRDR CONVERTER

Convert Red Dead Redemption 2 photo mode (PRDR) files to PNG, JPG or WebP in your browser.

## Files
- `index.html` the whole app
- `logo.jpg`, `icon-192.png`, `icon-512.png` logo and app icons
- `manifest.webmanifest`, `sw.js` install and offline support
- `.github/workflows/deploy.yml` GitHub Pages deploy

## Deploy
1. Upload all files to a GitHub repo, keeping the folder layout.
2. Settings > Pages > Source: **GitHub Actions**.
3. Push to `main`. The site publishes automatically.

Edit the `ABOUT` block at the top of the script in `index.html` to set your own About text and links.
